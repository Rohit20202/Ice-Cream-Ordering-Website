# Ice Cream Ordering Website

This project is a simple Ice Cream Ordering Website developed using **PHP, HTML, CSS, and MySQL**. The website allows users to browse different ice cream products, view details, and place orders online. It also includes an admin panel where the admin can manage products, view orders, and handle messages from users.

The main goal of this project is to demonstrate the basic functionality of an online food ordering system, including user authentication, product management, and order processing.

## Features

* User registration and login system
* Browse and view ice cream products
* Add products and manage them through the admin panel
* View and manage customer orders
* Simple and responsive user interface

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript

This project was created for learning purposes and to understand how a basic e-commerce style website works using PHP and MySQL.
